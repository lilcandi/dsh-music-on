## 0.2.0

底部频谱、配色主题与设置页在这一版重做，同时把「音景」功能区整块移除。

### 频谱

之前无论窗口多宽，频谱最多只铺到 286px：柱宽被夹在 `[2,4]`、缝被夹在 `[1.5,2]`，pitch 上限 6px，48 根柱就此封顶。现在宽度由剩余空间反解 —— `gap = (w - barW * n) / (n - 1)` —— 整排在任意尺寸下都精确等于容器宽度。1440px × 48 柱实测柱宽 15.00px、缝 15.32px、整排 1440.0px。

- 柱数上限 96 → **160**
- 新增**频谱宽度**设置（占窗口宽度 20–100%，按 5 对齐）
- 样式扩到七种：圆点、粗柱、方块阵列、对称声波、折线、时域波形、关闭。`blocks` 与 `mirror` 是本版真实绘制的新画法，不是选项名

### 主题

七套配色：鲸鱼蓝白（默认）、极光青紫、薄荷绿、落日橙、玫瑰粉、霓虹赛博、极简灰白。

它们此前**视觉上完全相同**，原因是不在调色板而在权重：主题块写成了 `:where([data-dmo-theme='x'])`，`:where()` 把选择器权重归零，而默认令牌块是 `(0,1,0)`，主题块永远赢不了。改用真选择器后七套才真正区分开，60 余处硬编码颜色也收敛成 `rgba(var(--dmo-rgb), α)` 三元组，半透明的线、光晕、玻璃一并跟着主题走。

### 移除

「音景」是从界面到落盘整链摘掉的，不只是把入口藏起来：控制器、IndexedDB 缓存、静态资源路由、面板分区、七条随包分发的 WAV 全部移除。宿主 `inject` 从 `['connection', 'webServer']` 收窄为 `['connection']`，HTTP 路由从三条减到两条。

### 修复

设置分区的说明文字原先直接落在宿主半透明面板上，`#5a6c92` 的 11.5px 小字对比度只有 **2.0:1**，几乎看不见。现在分区自带玻璃底，并加了断言把对比度钉住。

### 商店截图

截图脚本改为**先真拖入一段音频再拍**：页内现场合成 24 秒 WAV 交给插件，等自动播放与频谱跑起来。所以一次干净的运行同时就是「拖入即播」的端到端验证 —— 链路断了，频谱那张会拍成一条平底噪。
